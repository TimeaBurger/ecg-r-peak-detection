# ECG R-Peak Detection

A Python project that detects heartbeats in ECG recordings by implementing the Pan–Tompkins algorithm from the original paper. It benchmarks the algorithm against a threshold-based baseline on the expert-annotated MIT-BIH Arrhythmia Database and analyses how detection errors distort clinical heart rate variability metrics.

Developed as part of the course *Programming with Python* at IU International University of Applied Sciences. Full title: *Python-Based R-Peak Detection in ECG Signals: Implementation and Evaluation of the Pan–Tompkins Algorithm on the MIT-BIH Arrhythmia Database*.

Status: in development
